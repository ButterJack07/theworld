# The World · 文明经营游戏

一个基于纯 HTML 静态页面的放置类模拟经营游戏。打开即玩，无需任何依赖。

## 运行方式

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管：

```bash
# 例如用 Python
python -m http.server 8080
```

## 当前功能

### 地图
- 30 × 20 网格地图，陆地 / 海洋两种地形
- 海洋贴边生成且整体连通，水域比例控制在 15%–30%
- 莫兰迪色系配色（米白背景、灰蓝海洋、灰绿陆地），无渐变
- 地图由种子确定性生成，刷新页面地图保持不变

### 建筑与小人
- 建筑统一为**圆角矩形卡通风**（阴影 + 主体 + 屋顶带 + 门 + 专属徽记），莫兰迪配色；**砖瓦屋**、**四合院**、**伐木工场**与**采矿工场**拥有独立建模（砖瓦屋瓦檐宽出墙体、四合院四周合围中央天井、伐木工场圆锯盘工棚、采矿工场井架天轮与矿车）
- 建筑不再是面板直建：先通过**合成器**合成建筑成品（进入物品栏，占据 1×1），再从物品栏**拖到地图**上安装
- **茅草屋**（一级住宅）：每座可容纳 1 人，不产资源
- **砖瓦屋**（二级住宅）：占地 2×2，每座可容纳 5 人，不产资源
- **四合院**（三级住宅）：占地 4×4，每座可容纳 25 人，不产资源
- **小人**：静态圆形单位，占据一格，围绕住宅逐圈扩散寻找陆地生成、互不重叠且避开建筑；每月增长 1 人，上限 = 茅草屋数量 × 1 + 砖瓦屋数量 × 5 + 四合院数量 × 25

### 合成与建造
- 左上角「**合成列表**」（📜 按钮展开）面板展示全部配方，分为两组：**材料合成** 与 **建筑合成**；「**扩建**」（🏗️ 按钮展开）面板展示建筑自动升级规则（信息展示，升级仍由摆放自动合并触发）
- **合成器**（3×3）放入材料后，下方列出**所有**可合成的成品（每个成品带「合成」按钮），点击其中一个即可合成，材料消耗、成品进入物品栏；物品栏满时无法合成
- 建筑成品从物品栏**拖到地图上安装**：拖动时悬停格显示落点预览（蓝色=可放 / 红色=不可放，可放时还会显示建筑半透明预览），松手即安装；多格建筑（砖瓦屋 2×2、四合院 4×4、伐木工场 2×2、采矿工场 2×2）按左上角落点预览
- 放置校验：必须是陆地、不与已建建筑 / 小人重叠；**钓船小屋必须临水**（四邻含海洋）；**伐木小屋必须建在森林上**；**采矿小屋必须建在山地或矿洞上**（未揭示的地块不能建造）
- 建筑成本与产出（**所有建筑统一每月产出一次**；住宅与工场**没有直接配方**，只能通过地图合并升级）：
  - **茅草屋**：1 木板 + 1 石头 → 纯住宅，每座 +1 人口容量（不产资源）
  - **砖瓦屋**：占地 2×2 的二级住宅，每座 +5 人口容量（不产资源）；**无直接配方**，地图上任意 4 个茅草屋摆成 2×2 会**自动合并升级**为砖瓦屋
  - **四合院**：占地 4×4 的三级住宅，每座 +25 人口容量（不产资源）；**无直接配方**，地图上任意 4 个砖瓦屋拼成 2×2 一块（合计覆盖 4×4）会**自动合并升级**为四合院
  - **伐木小屋**：1 木板 + 1 石头 → 每月产出 5 木头（必须建在森林上）
  - **采矿小屋**：1 木头 + 2 石头 → 每月产出 4 石头 + 1 矿物（铁 60% / 金 15% / 铜 15% / 稀有矿物 10%）（必须建在山地或矿洞上）
  - **伐木工场**：占地 2×2，**无直接配方**，地图上任意 4 个伐木小屋摆成 2×2 会**自动合并**为伐木工场 → 每月产出 **25 木头**
  - **采矿工场**：占地 2×2，**无直接配方**，地图上任意 4 个采矿小屋摆成 2×2 会**自动合并**为采矿工场 → 每月产出 **20 石头 + 5 矿物**（铁 60% / 金 15% / 铜 15% / 稀有矿物 10%）
  - **钓船小屋**：2 木板 + 1 布匹 → 每月产出 2 食物（必须临水）
  - **钓船码头**：占地 3×1 / 1×3，**无直接配方**，地图上任意 3 个钓船小屋排成横 / 竖直线会**自动合并**为钓船码头 → 每月产出 **10 食物**；朝向自动对准水域（船坞在岸、木制浮台伸向水面），横排对应东西向、竖排对应南北向
- 信息面板逐条展示各建筑产出量；人口上限 = 茅草屋数量 × 1 + 砖瓦屋数量 × 5 + 四合院数量 × 25

### 地貌与基地
- 陆地上随机分布**成块的特殊地貌**（一团 3~20 格，总面积约占陆地 50%）：**草原**（最常见）、**森林**、**黏土山**、**湿地**（最少见）、**山地**；**矿洞**每张地图**固定刷一个**（大小 6~12）。除矿洞和平原外，并非每张地图都会刷出所有地貌
- 未揭示的地块一律按**平原**显示与产出；已揭示的地貌在地图上涂上专属颜色并显示团边界
- **基地**是地图上的灰色可拖动缩放窗口（默认居中 2×2）。每个阶段（1 个月 = 30 天）基地覆盖的每块格子按当前地貌**只有 10% 概率完成一次产出**（平原：2 木头 或 2 石头 或 1 铁矿 或 1 黏土 或 1 浆果），覆盖同一地貌多格则产出叠加；覆盖到**海洋**则按海洋地貌计算，每格产 1 条鱼
- 特殊地貌只在**陆地**上成块刷新
- **发掘**：特殊地貌初始隐藏，需要覆盖并产出逐步「发掘」。某团的累计产出次数达到 **面积 × 2** 即揭示整团；基地覆盖该团多格时一起计数，覆盖越多揭示越快
- 已揭示地貌产出更高：草原 3 木头/1 浆果/1 石头，森林 3~6 木头，黏土山 2~4 黏土，湿地多种物资，山地 3~5 石头 + 0~2 铁矿，矿洞 2~3 石头 +（2~4 铁矿 70% / 金 10% / 铜 15% / 琥珀或钻石 5%）
- 点击基地内空地：信息面板显示基地覆盖面积与各地貌类型、格数（已揭示地貌如实显示，其余显示为平原）
- **双击任意地块**：信息面板显示该地块的地貌类型与其每月产出内容

### 物品栏
- 8 列 × 4 行连续网格（42px/格），分割线样式与地图一致
- 初始物品栏提供：木头 ×10、石头 ×6、铁矿 ×3、布匹 ×2
- 所有物品（含材料与建筑成品）统一占据 **1×1** 格子
- **拖动**：默认每次拖动 1 个物品；按住 0.5s（物品冒出金色光晕与「整组」角标）再拖动则为整组移动
- 物品可在栏内拖动、堆叠合并，目标区域显示天蓝色描边预览（带柔光）；拖到同种物品堆上自动合并数量
- 每堆物品上限 100；**双击**某堆可将所有同种物品堆合并到该堆上
- 放置校验：越界 / 与其他物品重叠时不允许放置

### 合成器与配方
- 3×3 连续网格（42px/格）
- 物品可在物品栏与合成器之间双向拖动（同样支持拖 1 个 / 长按 0.5s 拖整组），同类自动堆叠；建筑成品不能放回合成器
- 材料合成：
  - 木板 = 2 木头
  - 布匹 = 1 木头 + 1 石头
  - 砖块 = 2 石头 + 1 铁矿
  - 金矿 = 2 铁矿 + 1 木头
- 建筑合成（见上「合成与建造」）

### 时间与速度
- 时间制：1 tick = 1 天，一年 **12 个月**（每月 30 天，共 360 天）
- 游戏循环 500ms 一次 tick，1 倍速 = 0.5 秒/天，2 倍速 = 0.25 秒/天
- 标题下实时显示「X 年 Y 月」；所有产出阶段（建筑、基地）与人口增长统一为**每月一次**
- 左上角「**▶ 暂停**」按钮循环切换：1倍速 → 2倍速 → 暂停
- 右上角显示人口（当前 / 容量）与文明程度（生产成功时 +产出量）
- **开场动画**：每次开始游戏（首次加载与「重新开始」）时，标题「The World」逐字淡入浮现，副标题与地图/信息/物品栏/合成器/按钮排等组件分层错峰浮入

### 操作
- 左上角按钮（**⚙️ 设置** 位于最左）：**⚙️ 设置**（打开设置菜单）、**📜 合成**（展开 / 收起合成列表）、**🏗️ 扩建**（展开 / 收起建筑自动升级规则）、**▶ 暂停**（1倍速 → 2倍速 → 暂停循环）
- **⚙️ 设置菜单**（选项卡式，两个标签，固定大小；打开时默认暂停游戏并盖上黑色半透明遮罩，关闭/点 ✕/点遮罩后恢复打开前的速度）：
  - **操作说明**：完整列出地图、物品与合成、按钮的操作指引（点击建筑查看信息、双击地块查看地貌、长按物品拖整组、双击合并堆叠、拖动基地边框缩放等）
  - **重新开始**：打开重启菜单，**询问是否确认重新开始**；点击「确认重新开始游戏」按钮后生成新种子并清空当前进度
- **地图悬停**：显示当前单元格坐标
- **安装建筑**：从物品栏把建筑成品拖到地图目标格，松手安装（悬停时有落点预览）

## 数据持久化

- 地图种子保存在 `localStorage`（key: `tw-seed`），刷新页面不换地图
- 游戏状态保存在 `localStorage`（key: `tw-game`），每 5 个 tick 自动保存，含人口、小人位置、已建建筑位置（含茅草屋 / 砖瓦屋 / 四合院 / 伐木工场 / 采矿工场）、文明程度、日期、物品栏与合成器内容
- 存档带版本号（`version: 2`）；**旧版存档（天制）不兼容，加载时自动重新开始**

## 项目结构

```
TheWorld/
├── index.html        # 页面骨架 + 引入 CSS / JS
├── css/
│   └── style.css     # 全部样式（莫兰迪配色、面板、物品格、合成列表等）
└── js/
    ├── data.js       # 常量与数据：地图尺寸、物品/图标/建筑/配方定义、网格参数
    ├── map.js        # 噪声与确定性地图生成（含湖泊消除、水域比例控制）
    ├── world.js      # 地图绘制、建筑实体绘制、小人、建造放置校验与安装、悬停预览
    ├── state.js      # localStorage 持久化：种子、存档读写、重置
    ├── inventory.js  # 物品栏网格、堆叠合并、长按整组拖动、物品栏拖放
    ├── crafting.js   # 合成器网格、配方匹配、合成结果列表、合成列表面板、拖放
    └── main.js       # DOM 绑定、倍速/暂停控制、游戏循环 tick、状态栏与启动流程
```

> 说明：脚本按 `data → map → world → state → inventory → crafting → main` 顺序加载，
> 各模块通过全局 `window.Game` 命名空间共享状态与函数（不使用 ES modules，保证双击 `index.html`
> 以 `file://` 协议直接打开即可运行）。

# The World · 文明经营游戏

一个基于纯 HTML 静态页面的放置类模拟经营游戏。打开即玩，无需任何依赖。

## 运行方式

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管：

```bash
# 例如用 Python
python -m http.server 8080
```

## 当前功能

### 地图
- 30 × 20 网格地图，陆地 / 海洋两种地形
- 海洋贴边生成且整体连通，水域比例控制在 15%–30%
- 莫兰迪色系配色（米白背景、灰蓝海洋、灰绿陆地），无渐变
- 地图由种子确定性生成，刷新页面地图保持不变

### 建筑与小人
- 建筑统一为**圆角矩形卡通风**（阴影 + 主体 + 屋顶带 + 门 + 专属徽记），莫兰迪配色
- 建筑不再是面板直建：先通过**合成器**合成建筑成品（进入物品栏，占据 1×1），再从物品栏**拖到地图**上安装
- **茅草屋**（人口建筑）：初始不配备，需自行合成安装；每 10 秒产出 1 粮食，每座可容纳 5 人
- **小人**：静态圆形单位，占据一格，围绕茅草屋逐圈扩散寻找陆地生成、互不重叠且避开建筑；每 20 秒增长 1 人，上限 = 茅草屋数量 × 5

### 合成与建造
- 左上角「**合成列表**」面板展示全部配方，分为两组：**材料合成** 与 **建筑合成**
- **合成器**（3×3）放入材料后，下方列出**所有**可合成的成品（每个成品带「合成」按钮），点击其中一个即可合成，材料消耗、成品进入物品栏；物品栏满时无法合成
- 建筑成品从物品栏**拖到地图上安装**：拖动时悬停格显示落点预览（蓝色=可放 / 红色=不可放，可放时还会显示建筑半透明预览），松手即安装
- 放置校验：必须是陆地、不与已建建筑 / 小人重叠；**钓船码头必须临水**（四邻含海洋）
- 建筑成本与产出：
  - **茅草屋**：2 木板 + 1 布匹 → 每 10s 产出 1 粮食（每座 +5 人口容量）
  - **伐木场**：4 木板 + 1 石头 → 每 8s 产出 2 木头
  - **采矿场**：2 砖块 + 1 布匹 → 每 12s 产出 1 石头 + 1 铁矿
  - **钓船码头**：2 木板 + 2 布匹 + 1 金矿 → 每 6s 产出 2 食物（必须临水）
- 信息面板逐条展示各建筑产出量

### 物品栏
- 8 列 × 4 行连续网格（42px/格），分割线样式与地图一致
- 初始物品栏提供：木头 ×10、石头 ×6、铁矿 ×3、布匹 ×2
- 支持 1×1、1×2、2×2 等多格物品（木头、石头、铁矿、食物、布匹、金矿、木板、砖块），以及 1×1 的建筑成品
- **拖动**：默认每次拖动 1 个物品；按住 0.5s（物品冒出金色光晕与「整组」角标）再拖动则为整组移动
- 物品可在栏内拖动、堆叠合并，目标区域显示天蓝色描边预览（带柔光）；拖到同种物品堆上自动合并数量
- 每堆物品上限 100；**双击**某堆可将所有同种物品堆合并到该堆上
- 放置校验：越界 / 与其他物品重叠时不允许放置

### 合成器与配方
- 3×3 连续网格（42px/格）
- 物品可在物品栏与合成器之间双向拖动（同样支持拖 1 个 / 长按 0.5s 拖整组），同类自动堆叠；建筑成品不能放回合成器
- 材料合成：
  - 木板 = 2 木头
  - 布匹 = 1 木头 + 1 石头
  - 砖块 = 2 石头 + 1 铁矿
  - 金矿 = 2 铁矿 + 1 木头
- 建筑合成（见上「合成与建造」）

### 时间与速度
- 游戏循环 500ms 一次 tick，1 倍速 = 0.5 秒/天，2 倍速 = 0.25 秒/天
- 日期逐天显示（2 倍速下每个中间天都会经过），一年 365 天，标题下实时显示「X 年 X 天」
- 左上角圆形按钮循环切换：1倍速 → 2倍速 → 暂停
- 右上角显示人口（当前 / 容量）与文明程度（生产成功时 +产出量）

### 操作
- **重新开始**（左上角）：生成新种子，重新生成整张地图与游戏状态
- **地图悬停**：显示当前单元格坐标
- **安装建筑**：从物品栏把建筑成品拖到地图目标格，松手安装（悬停时有落点预览）

## 数据持久化

- 地图种子保存在 `localStorage`（key: `tw-seed`），刷新页面不换地图
- 游戏状态保存在 `localStorage`（key: `tw-game`），每 5 个 tick 自动保存，含人口、小人位置、已建建筑位置（含茅草屋）、文明程度、日期、物品栏与合成器内容

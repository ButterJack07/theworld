# The World · 文明经营游戏

一个基于纯 HTML 静态页面的放置类模拟经营游戏。打开即玩，无需任何依赖。

## 新手导引

**目标**：发展文明，从一座城镇中心扩张成繁荣的聚落。核心循环：**基地采集 → 合成建筑 → 分配劳动力 → 扩大产出 → 扩张与升级**。

### 开局
- 你拥有**一座城镇中心**（+3 人口容量）和**初始 2 名人口**。他们目前都是**探索者**，会自动为基地采集资源。
- 基地（地图上的灰色窗口）每月的产出次数 = **探索者人数**（空闲人口）；产出内容按基地覆盖地块的**类型与数量加权**决定（覆盖森林多就多产木头，覆盖山地多就多产石头）。

### 第一步：合成建筑
1. 把物品栏里的**木头、石头**等材料拖进**合成器**（右侧 3×3 区域）。
2. 合成器下方会列出可合成的成品，点击「合成」即可。
3. 合成的**建筑**（如伐木小屋）进入物品栏，从物品栏**拖到地图**上安装（蓝色=可放 / 红色=不可放）。
4. 优先建造**住宅**（茅草屋）提升人口上限，以及**生产力建筑**（伐木小屋、农田等）获得稳定资源。

### 第二步：分配劳动力
- 点击地图上的生产力建筑 → 信息面板 → 点「👥 劳动力分配」按钮，用 **+ / −** 调整该建筑的工人数。
- 每个工人每月产出一份，人越多产出越多；高级建筑（伐木工场、农庄等）最多可分配 **5 人**。
- **空闲人口自动成为探索者**，探索者数量决定基地产量与地貌揭示速度。

### 第三步：揭示地貌与扩张
- 特殊地貌（草原、森林、山地、矿洞等）初始隐藏，需要探索者持续覆盖逐步「发掘」。
- 某团的揭示进度 = 该团在基地内格数 × 探索者人数，累计达到 **团格数 × 2** 即整团揭示。
- **拖动基地边框**扩大覆盖范围：覆盖更多地貌 = 更多产出 + 更快揭示。
- **双击地块**可查看该地块的地貌与每月产出。

### 进阶玩法
- **合并升级**：4 个低级建筑摆成 2×2 自动合并为高级建筑（茅草屋→砖瓦屋、伐木小屋→伐木工场、农田→农庄…），高级建筑劳动力槽位更多、产能更高。
- 点击右上角「👥 劳动力」查看各工种与探索者的人数分布。
- 左上角「📜 合成」查看全部配方、「🏗️ 扩建」查看升级规则、「▶」切换 1 倍速 / 2 倍速 / 暂停。

## 运行方式

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管：

```bash
# 例如用 Python
python -m http.server 8080
```

## 当前功能

### 地图
- 30 × 20 网格地图，陆地 / 海洋两种地形
- 海洋贴边生成且整体连通，水域比例控制在 15%–30%
- 莫兰迪色系配色（米白背景、灰蓝海洋、灰绿陆地），无渐变
- 地图由种子确定性生成，刷新页面地图保持不变

### 建筑与小人
- 建筑统一为**圆角矩形卡通风**（阴影 + 主体 + 屋顶带 + 门 + 专属徽记），莫兰迪配色；**砖瓦屋**、**四合院**、**伐木工场**与**采矿工场**拥有独立建模（砖瓦屋瓦檐宽出墙体、四合院四周合围中央天井、伐木工场圆锯盘工棚、采矿工场井架天轮与矿车）
- 建筑不再是面板直建：先通过**合成器**合成建筑成品（进入物品栏，占据 1×1），再从物品栏**拖到地图**上安装
- **茅草屋**（一级住宅）：每座可容纳 1 人，不产资源
- **砖瓦屋**（二级住宅）：占地 2×2，每座可容纳 5 人，不产资源
- **四合院**（三级住宅）：占地 4×4，每座可容纳 25 人，不产资源
- **小人**：不在地图上实体显示，仅作为人口统计与劳动力池存在；围绕住宅逐圈扩散寻找陆地占用格子；每月增长随当前人口基数决定（每月新增 = 当前人口 × 10%，至少 1 人），直到人口上限 = 城镇中心数量 × 3 + 茅草屋数量 × 1 + 砖瓦屋数量 × 5 + 四合院数量 × 25

### 合成与建造
- 左上角「**合成列表**」（📜 按钮展开）面板展示全部配方，分为两组：**材料合成** 与 **建筑合成**；「**扩建**」（🏗️ 按钮展开）面板展示建筑自动升级规则（信息展示，升级仍由摆放自动合并触发）
- **合成器**（3×3）放入材料后，下方列出**所有**可合成的成品（每个成品带「合成」按钮），点击其中一个即可合成，材料消耗、成品进入物品栏；物品栏满时无法合成
- 建筑成品从物品栏**拖到地图上安装**：拖动时悬停格显示落点预览（蓝色=可放 / 红色=不可放，可放时还会显示建筑半透明预览），松手即安装；多格建筑（砖瓦屋 2×2、四合院 4×4、伐木工场 2×2、采矿工场 2×2、农庄 2×2、牧场 2×2）按左上角落点预览
- 放置校验：必须是陆地、不与已建建筑重叠；**钓船小屋必须临水**（四邻含海洋）；**伐木小屋必须建在森林上**；**采矿小屋必须建在山地或矿洞上**；**牧场覆盖的 4 格必须全部为已揭示的草原**（未揭示的地块不能建造）
- 建筑成本与产出（**所有建筑统一每月结算一次**；产出需要分配劳动力，n 个劳动力 → 产出 n × 基准 x）：
  - **城镇中心**：3 石头 + 2 木板 + 4 砖块 → 纯住宅，每座 +3 人口容量（不产资源）；**初始自带一座**
  - **茅草屋**：1 木板 + 1 石头 → 纯住宅，每座 +1 人口容量（不产资源）
  - **砖瓦屋**：占地 2×2 的二级住宅，每座 +5 人口容量（不产资源）；**无直接配方**，地图上任意 4 个茅草屋摆成 2×2 会**自动合并升级**为砖瓦屋
  - **四合院**：占地 4×4 的三级住宅，每座 +25 人口容量（不产资源）；**无直接配方**，地图上任意 4 个砖瓦屋拼成 2×2 一块（合计覆盖 4×4）会**自动合并升级**为四合院
  - **伐木小屋**：1 木板 + 1 石头 → 1 个劳动力槽位，每月生产 5 木头（必须建在森林上）
  - **采矿小屋**：1 木头 + 2 石头 → 1 个劳动力槽位，每月生产 4 石头 + 1 矿物（铁 60% / 金 15% / 铜 15% / 稀有矿物 10%）（必须建在山地或矿洞上）
  - **伐木工场**：占地 2×2，**无直接配方**，地图上任意 4 个伐木小屋摆成 2×2 会**自动合并**为伐木工场 → **至多 5 个劳动力**，满员每月生产 25 木头
  - **采矿工场**：占地 2×2，**无直接配方**，地图上任意 4 个采矿小屋摆成 2×2 会**自动合并**为采矿工场 → **至多 5 个劳动力**，满员每月生产 20 石头 + 5 矿物
  - **钓船小屋**：2 木板 + 1 布匹 → 1 个劳动力槽位，每月生产 2 食物（必须临水）
  - **钓船码头**：占地 3×1 / 1×3，**无直接配方**，地图上任意 3 个钓船小屋排成横 / 竖直线会**自动合并**为钓船码头 → **至多 5 个劳动力**，满员每月生产 10 食物；朝向自动对准水域（船坞在岸、木制浮台伸向水面），横排对应东西向、竖排对应南北向
  - **农田**：1 木板 + 1 石头 → 1 个劳动力槽位，每月生产 5 小麦（可建在任何陆地）
  - **农庄**：占地 2×2，**无直接配方**，地图上任意 4 个农田摆成 2×2 会**自动合并**为农庄 → **至多 5 个劳动力**，满员每月生产 25 小麦
  - **牧场**：占地 2×2，2 木板 + 1 布匹 → **至多 5 个劳动力**，满员每月生产 10 生肉（必须建在草原上，覆盖的 4 格全须为已揭示草原）
- 建筑合并升级时已分配的劳动力自动**结转**到新建筑（不超过其劳动力槽位上限）
- 信息面板展示各建筑**每月总产出**（n × 基准 x）；未分配劳动力时显示「请分配劳动力到该生产建筑」；人口上限 = 城镇中心数量 × 3 + 茅草屋数量 × 1 + 砖瓦屋数量 × 5 + 四合院数量 × 25

### 地貌与基地
- 陆地上随机分布**成块的特殊地貌**（一团 3~20 格，总面积约占陆地 50%）：**草原**（最常见）、**森林**、**黏土山**、**湿地**（最少见）、**山地**；**矿洞**每张地图**固定刷一个**（大小 6~12）、**森林**每张地图**至少一团**。除矿洞和平原外，并非每张地图都会刷出所有地貌
- 未揭示的地块一律按**平原**显示与产出；已揭示的地貌在地图上涂上专属颜色并显示团边界
- **基地**是地图上的灰色可拖动缩放窗口（默认居中 2×2）。**空闲劳动力视为探索者**，基地每月产出次数 = **探索者人数**（即基地每月最大生产值 = 空闲人口 = 总人口 − 已分配劳动力）；每次产出按基地覆盖地块的**类型与数量加权平均**决定内容（覆盖哪类地貌多，产出该类地貌的概率越高），如覆盖 2 格平原 1 格森林，则抽中平原的概率为 2/3；覆盖到**海洋**则按海洋地貌计算（每格产 1 条鱼）
- 特殊地貌只在**陆地**上成块刷新
- **发掘**：特殊地貌初始隐藏，需要覆盖并「发掘」。每团的**总揭示进度 = 团格数 × 2**；每月该团揭示进度增长 = **该团在基地内的格数 × 探索者人数**，达标即整团揭示（探索者越多、覆盖该团越多格，揭示越快）
- 已揭示地貌产出更高：草原 3 木头/1 浆果/1 石头，森林 3~6 木头，黏土山 2~4 黏土，湿地多种物资，山地 3~5 石头 + 0~2 铁矿，矿洞 2~3 石头 +（2~4 铁矿 70% / 金 10% / 铜 15% / 琥珀或钻石 5%）
- 点击基地内空地：信息面板显示基地覆盖面积与各地貌类型、格数（已揭示地貌如实显示，其余显示为平原）
- **双击任意地块**：信息面板显示该地块的地貌类型与其每月产出内容

### 物品栏
- 8 列 × 4 行连续网格（42px/格），分割线样式与地图一致
- 初始物品栏提供：木头 ×10、石头 ×6、铁矿 ×3、布匹 ×2
- 初始状态：基地内自带一座**城镇中心**，初始人口 **2**（均为探索者）
- 所有物品（含材料与建筑成品）统一占据 **1×1** 格子
- **拖动**：默认每次拖动 1 个物品；按住 0.5s（物品冒出金色光晕与「整组」角标）再拖动则为整组移动
- 物品可在栏内拖动、堆叠合并，目标区域显示天蓝色描边预览（带柔光）；拖到同种物品堆上自动合并数量
- 每堆物品上限 100；**双击**某堆可将所有同种物品堆合并到该堆上
- 放置校验：越界 / 与其他物品重叠时不允许放置

### 合成器与配方
- 3×3 连续网格（42px/格）
- 物品可在物品栏与合成器之间双向拖动（同样支持拖 1 个 / 长按 0.5s 拖整组），同类自动堆叠；建筑成品不能放回合成器
- 材料合成：
  - 木板 = 2 木头
  - 布匹 = 1 木头 + 1 石头
  - 砖块 = 2 石头 + 1 铁矿
  - 金矿 = 2 铁矿 + 1 木头
  - 面包 = 2 小麦
- 建筑合成（见上「合成与建造」）：茅草屋 / 伐木小屋 / 采矿小屋 / 钓船小屋 / 农田 / 牧场

### 时间与速度
- 时间制：1 tick = 1 天，一年 **12 个月**（每月 30 天，共 360 天）
- 游戏循环 500ms 一次 tick，1 倍速 = 0.5 秒/天，2 倍速 = 0.25 秒/天
- 标题下实时显示「X 年 Y 月」；所有产出阶段（建筑、基地）与人口增长统一为**每月一次**
- 左上角「**▶ 暂停**」按钮循环切换：1倍速 → 2倍速 → 暂停
- 右上角显示**👥 劳动力**（弹出劳动力分配菜单）、人口（当前 / 容量）、文明程度（生产成功时 +产出量）与当前**游戏模式**
- **劳动力分配菜单**：点右上角「👥 劳动力」在左侧展开面板（与合成列表一致），显示总人口 / 已分配 / 探索者，并把**探索者**（空闲劳动力）与各**工种**（伐木工 / 采矿工 / 渔夫 / 农民 / 牧民）并列列为劳动力类型统计人数，用进度条可视化各类型占总人口的比例
- **分配劳动力**：点击地图上的生产力建筑查看信息面板，点面板中的「👥 劳动力分配」按钮弹出该建筑的**劳动力分配窗口**，显示当前 / 最多劳动力与当前空闲人口（探索者），用 **+ / −** 调整（不可超过建筑槽位，也不可超过空闲人口）；点击遮罩或 ✕ 关闭
- **开场动画**：在**进入游戏**（新开世界或继续发展）时播放（标题「The World」逐字淡入浮现，副标题与地图/信息/物品栏/合成器/按钮排等组件分层错峰浮入）；**刷新页面不播放**

### 游戏模式
- 进入游戏一律经过**开始菜单**选择游戏模式；**三种模式各自独立存档**（互不影响进度与地图）
- 点选某个模式后：该模式**已有历史游玩记录**时，弹出选择——「**继续发展**」恢复上次进度 /「**重新开始**」开新世界；**无记录**则直接开始新游戏
- **文明模式**：文明指数达到 **9999** 即获胜，按**游戏内历时**（X 年 Y 月 Z 天）计算成绩排名；历史最佳前 10 名记录于本地
- **科技模式**：发展出任一项高级科技即获胜，按历时排名 —— **尚未开放**（高级科技仍在设计中）
- **自由模式**：没有胜利标准，自由发展你的文明；返回主菜单时以当前**文明指数**记录一次成绩
- 胜利后（文明模式）可「**继续发展**」或「**返回开始菜单**」重新选择模式
- **排行榜**：开始菜单右下角「🏆 排行榜」打开榜单弹窗，可切换**本地排行 / 网络排行**（网络排行暂未开放），并分**三种模式**各自排行——文明 / 科技模式按历时（越小越好），自由模式按文明指数（越大越好），各模式保留前 10 名

### 操作
- 左上角按钮（**⚙️ 设置** 位于最左）：**⚙️ 设置**（打开设置菜单）、**📜 合成**（展开 / 收起合成列表）、**🏗️ 扩建**（展开 / 收起建筑自动升级规则）、**▶ 暂停**（1倍速 → 2倍速 → 暂停循环）
- **⚙️ 设置菜单**（选项卡式，两个标签，固定大小；打开时默认暂停游戏并盖上黑色半透明遮罩，关闭/点 ✕/点遮罩后恢复打开前的速度）：
  - **操作说明**：完整列出地图、物品与合成、按钮的操作指引（点击建筑查看信息、双击地块查看地貌、长按物品拖整组、双击合并堆叠、拖动基地边框缩放等）
  - **返回主菜单**：点击后直接返回开始菜单重新选择游戏模式（当前模式的进度保留在各自存档中，无需确认）
- **地图悬停**：显示当前单元格坐标
- **安装建筑**：从物品栏把建筑成品拖到地图目标格，松手安装（悬停时有落点预览）

## 数据持久化

- 地图种子保存在 `localStorage`，**按模式区分**（key: `tw-seed-{模式}`），刷新页面不换地图
- 游戏状态保存在 `localStorage`，**按模式区分**（key: `tw-game-{模式}`，如 `tw-game-civilization`），每 5 个 tick 自动保存，含人口、小人位置、已建建筑位置（含茅草屋 / 砖瓦屋 / 四合院 / 伐木工场 / 采矿工场）、文明程度、日期、**游戏模式**、物品栏与合成器内容
- 各模式历史最佳成绩保存在 `localStorage`（key: `tw-rank`），文明 / 科技模式记录「历时天数」，自由模式记录「文明指数」，各模式保留前 10 名
- 存档带版本号（`version: 2`）；**旧版存档（天制）不兼容，加载时自动重新开始**；旧版单一存档（`tw-game`）会在首次运行时自动迁移到文明模式

```
    ├── crafting.js   # 合成器网格、配方匹配、合成结果列表、合成列表面板、拖放
    └── main.js       # DOM 绑定、倍速/暂停控制、游戏循环 tick、状态栏与启动流程
```

> 说明：脚本按 `data → map → world → state → inventory → crafting → main` 顺序加载，
> 各模块通过全局 `window.Game` 命名空间共享状态与函数（不使用 ES modules，保证双击 `index.html`
> 以 `file://` 协议直接打开即可运行）。
